# Publish TaxPrep as a website

Visitors use one HTTPS website on mobile or desktop. They do not install anything.
The Next.js frontend calls the Python API, which stores accounts and returns in
Postgres. No Docker is required for this deployment.

1. Push this repository to GitHub.
2. Create a Postgres database (for example, Neon), and copy its connection URL.
3. In Render, create a Blueprint from this repository's root `render.yaml`.
   It runs the backend as a native Python service. Set DATABASE_URL to the
   Postgres URL. Set DATA_KEY to a generated Fernet key, keep it backed up, and
   preserve it on redeploys. JWT_SECRET is generated by the blueprint.
4. In Vercel, import the same repository and set Root Directory to
   `taxprep/frontend`. Set NEXT_PUBLIC_API_URL to the Render HTTPS URL, with no
   trailing slash, then deploy.
5. Set the Render CORS_ORIGINS variable to the exact Vercel HTTPS origin, then
   redeploy the backend. Never put DATA_KEY or database credentials in Vercel's
   NEXT_PUBLIC variables.
6. Check the API's `/health`, then open the Vercel URL, create an account, start
   a sample return, calculate, download a PDF, and sign out/in to check resume.

Generate DATA_KEY with Python after installing the backend dependencies:

```sh
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Native Python hosting also needs Tesseract for scanned-image OCR. Manual income
entry does not need it. Verify OCR availability before offering image uploads.
Resolve the frontend security audit findings documented in README.md before
opening the application to real taxpayer data.

## Visitor instructions

Open the published website in Safari, Chrome, Edge, or Firefox. Create an account,
choose **Start 2025 return**, and complete **About you → Residency → Interview →
Income**. Select **Calculate my return**, review warnings, and choose
**Download filing package (PDF)**. Review missing attachments and sign the forms
before following the mailing instructions. Saved returns reopen from the dashboard.

The app prepares TY2025 and does not submit returns electronically.
