# TaxPrep Frontend — Phase 3
Next.js 14 (App Router) + TypeScript + Tailwind.

Pages: `/` auth · `/dashboard` returns list · `/return/[id]` 5-step wizard
(About you → Residency → adaptive Interview → Income → Results with live form
ledger and PDF filing-package download).

```bash
cp .env.local.example .env.local   # point at the API
npm install && npm run dev          # http://localhost:3000
```
