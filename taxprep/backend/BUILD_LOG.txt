DEPLOYMENT HARDENING (2026-07-05)
Preparing for free-tier hosting (Neon + Render + Vercel) surfaced two real bugs:
1. Dockerfile never installed tesseract-ocr/poppler-utils -> OCR would fail silently in any containerized deploy (worked locally only because host had them). Fixed: apt-get install in Dockerfile.
2. DATABASE_URL from Neon/most managed Postgres starts with "postgres://"; SQLAlchemy 2.x rejects that scheme. Fixed: _normalize_db_url() rewrites to "postgresql://".
Also added: psycopg2-binary driver, sslmode=require default for non-sqlite connections (Neon requires SSL), pool_pre_ping=True (avoids stale-connection errors after Render free-tier sleep/wake), $PORT support in CMD (Render assigns a dynamic port), CORS_ORIGINS env var (defaults to "*", tightened to the Vercel domain per DEPLOY.md step 4), split requirements.txt (prod) / requirements-dev.txt (adds pytest/httpx/pdfplumber) so the production image doesn't carry test tooling.
Added render.yaml blueprint, .gitignore, DEPLOY.md (step-by-step: Neon free Postgres -> Render free Docker web service -> Vercel free Next.js hosting).
Reran full suite after all changes: 42/42 passing (confirms normalize/SSL logic didn't break local sqlite dev path).

LOCAL-DB SUPPORT (2026-07-05)
User wants to self-host Postgres on their own PC (reached via ngrok tunnel) instead of Neon, to avoid free-tier caps at the cost of app uptime being tied to their machine.
BUG CAUGHT: session.py hardcoded sslmode=require for any non-sqlite DATABASE_URL. A local Postgres install has no SSL certificate configured -> connection would be refused outright. Fixed: DB_SSLMODE env var (default "require", set "disable" for local/self-hosted).
Added: LOCAL-DB.md (ngrok tcp tunnel walkthrough — no router port-forward needed since ngrok's agent makes an outbound connection; DATABASE_URL construction; caveats: ngrok free address changes on restart, must prevent OS sleep, no automatic backups, security note on password strength).
render.yaml: added DB_SSLMODE var (default require, documented to flip to disable for this path).
Reran full suite after config change: 42/42 passing.
